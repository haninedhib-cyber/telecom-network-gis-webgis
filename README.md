## 🎯 Main Objectives

- Understand copper and fiber-optic access networks.
- Explore FTTx and GPON architectures.
- Discover AirPON technology.
- Study the use of GIS in telecommunications.
- Build a local GIS/WebGIS learning environment.

## 🗺️ GIS & WebGIS Project

The practical work involved setting up a local environment
to explore spatial data management and web mapping.

**Main database layers:**

`centrale_optique` · `olt` · `sro` · `ftb` · `fibre_optique` · `pro` · `clients`

> **Note:** This environment was developed for learning and demonstration
> purposes. It does not represent Tunisie Telecom's production systems.
