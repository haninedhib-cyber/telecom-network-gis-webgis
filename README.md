## 🗂️ Spatial Database — `telecom_sig`

The local GIS/WebGIS environment explored during the internship used a PostgreSQL/PostGIS database named `telecom_sig`.

| Spatial layer | Purpose |
|---|---|
| `centrale_optique` | Optical central offices |
| `olt` | Optical Line Terminals |
| `sro` | Optical distribution cabinets |
| `ftb` | Fiber termination boxes |
| `fibre_optique` | Fiber-optic infrastructure |
| `pro` | Telecommunications infrastructure |
| `clients` | Client-related geographic data |

> **Note:** This database describes the local learning and demonstration environment, not necessarily Tunisie Telecom's production database.

- Understanding telecommunications access networks and optical infrastructure.
- Discovering how GIS supports network asset management.
- Exploring spatial databases and geographic data layers.
- Learning the principles of WMS, WFS, WFS-T and CSW.
- Understanding the integration of desktop GIS, map servers and web mapping.
- Connecting telecommunications engineering with geospatial technologies.
